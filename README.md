# Snapshooter

Snapshooter is a Unity prototype that combines photography with hidden-object gameplay.

The player takes a photo of the environment and then uses that photo to find and interact with objects in the game world.

[![Snapshooter Trailer Preview](https://img.youtube.com/vi/IqL6vvpcknU/0.jpg)](https://youtu.be/IqL6vvpcknU)

## Gameplay

The core mechanic is based on taking pictures of the scene and using the resulting image as part of the gameplay.

The project explores the interaction between the 3D game world, camera rendering, and photo-based object interaction.

## Technical Highlights

- Custom photo-taking system using an in-game camera
- Interaction between captured images and objects in the 3D scene
- Runtime texture and image processing
- World-space and screen-space coordinate handling
- Custom gameplay systems built around the photography mechanic
- Modular Unity project structure

## Tech Stack

- Unity
- C#
- URP
- Zenject
- Shader Graph

## About the Project

Snapshooter is a personal project created to experiment with gameplay mechanics based on photography and the relationship between a captured 2D image and the underlying 3D environment.

The project is a playable prototype and is primarily focused on implementing and exploring the core mechanic.
