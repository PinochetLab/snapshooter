# Snapshooter

> Игра о том, как один снимок может переписать реальность.

**Snapshooter** — это необычная головоломка для ПК, где фотография становится не просто воспоминанием, а инструментом изменения мира. Ваша задача — найти правильный ракурс, чтобы совместить изображение на фото с окружающей реальностью. Удачный кадр заставляет объекты появляться из ниоткуда или исчезать навсегда.

## 🧩 Игровой процесс

- **Фотоаппарат — главный инструмент**. Вы не стреляете и не строите — вы снимаете.
- **Реальность vs Фотография**. Мир вокруг и то, что вы видите в видоискателе, могут не совпадать. Ваша задача — сделать их единым целым.
- **Последствия каждого кадра**. Совместите снимок с окружением — и объект с фотографии проявится в реальном мире или бесследно исчезнет.
- **Нестандартные головоломки**. Каждый уровень требует свежего взгляда и творческого подхода к выбору ракурса.
